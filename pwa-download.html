Was ist eine PWA?

Eine Progressive Web App (PWA) ist eine App, die Sie direkt aus dem Internet-Browser herunterladen können — ganz ohne App Store. Sie wird auf Ihrem Gerät gespeichert und funktioniert fast wie eine normale App.

So installieren Sie CallSafe

1
Klicken Sie oben auf „Jetzt App installieren" – der Button erscheint sobald Ihr Browser bereit ist.
2
Bestätigen Sie die Installation in dem kleinen Fenster, das erscheint. Klicken Sie auf „Installieren".
3
Fertig! CallSafe erscheint nun auf Ihrem Startbildschirm – genauso wie eine normale App.

Auf iPhone oder iPad (Safari)

1
Öffnen Sie diese Seite in Safari (nicht in Chrome oder Firefox).
2
Tippen Sie unten auf das Teilen-Symbol (Viereck mit Pfeil nach oben).
3
Wählen Sie „Zum Home-Bildschirm" und dann „Hinzufügen".
